# Symbolen gebruiken ## Wat is dit? Een symbool is een object dat je één keer maakt en daarna zo vaak plaatst als je wilt, zoals een stoel, lamp of tafel. Pas je het symbool aan, dan veranderen alle geplaatste exemplaren mee. ## Hoe werkt het? - Maak een symbool van geselecteerde objecten. Het komt in de Resource Manager te staan. - Plaats het symbool vanuit de Resource Manager in je tekening. - Bewerk het symbool om alle exemplaren tegelijk aan te passen. - Verschil met een groep: een groep is één los exemplaar, een symbool is overal gekoppeld.
